# RAG-система для рекомендаций по дизайну интерьера

## 🏠 Описание проекта
Интеллектуальная система, которая генерирует персонализированные рекомендации по дизайну интерьера на основе базы профессиональных правил и документов. Использует современные модели машинного обучения для поиска информации и генерации ответов.

## 🎯 Основные функции
- Поиск релевантной информации в базе знаний
- Генерация рекомендаций с ссылками на источники
- Обработка PDF-документов
- Визуализация векторных представлений
- Интерактивный режим вопрос-ответ

## 🛠️ Технологии
- **Python** – основной язык разработки
- **Sentence Transformers** – создание эмбеддингов (`intfloat/multilingual-e5-large`)
- **FAISS** – векторный поиск
- **Qwen/Qwen3Guard-Gen-4B** – языковая модель для генерации
- **PyTorch** – работа с нейросетевыми моделями
- **UMAP** – визуализация многомерных данных
- **pdfplumber** – обработка PDF-файлов

## 🏗️ Архитектура системы
1. **Загрузка документов** – извлечение текста из PDF
2. **Разбиение на чанки** – 1000 символов с перекрытием 200
3. **Создание эмбеддингов** – векторные представления текста
4. **Поиск релевантного** – FAISS для быстрого поиска
5. **Генерация ответа** – LLM с контекстом из найденных фрагментов
6. **Интерактивный интерфейс** – диалоговый режим работы

## 📊 Демонстрируемые навыки
### **Data Engineering**
- Обработка неструктурированных данных (PDF, текст)
- Создание пайплайнов обработки документов
- Разработка алгоритмов разбиения текста

### **Machine Learning & NLP**
- Реализация RAG-архитектуры
- Работа с трансформерными моделями
- Создание и использование эмбеддингов
- Fine-tuning промптов для улучшения ответов

### **Информационный поиск**
- Семантический поиск по векторной базе
- Ранжирование результатов по релевантности
- Работа с метриками схожести

### **Domain Expertise**
- Понимание предметной области дизайна интерьера
- Структурирование профессиональных знаний
- Генерация практических рекомендаций

## 🚀 Особенности реализации
- **Обязательное цитирование** – все ответы содержат ссылки на источники
- **Гибкая конфигурация** – настраиваемые параметры через `RAGConfig`
- **Резервные стратегии** – fallback-механизмы при ошибках
- **Визуализация** – UMAP для анализа векторного пространства

## 📈 Оценка качества
- **Точность поиска** – релевантность найденных фрагментов
- **Качество генерации** – полезность и структурированность ответов
- **Производительность** – время обработки запросов
